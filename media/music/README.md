# 🎵 Музыкальные файлы Velantrim

Эта папка предназначена для двух музыкальных файлов, которые владелец предоставит позднее.

После загрузки будут уточнены имена файлов, формат и метаданные композиций. Пока исходные файлы не предоставлены, фиктивные MP3/MP4 не создаются.

Ссылки и возможность воспроизведения в корневом README будут добавлены отдельно после проверки форматов, размера, доступа в приватном репозитории и работы на GitHub с компьютера и телефона.
