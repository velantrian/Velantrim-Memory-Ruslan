## Что добавлено

Бытие 2–3 и Матфея 6–7: 62 новых смысловых записей. Всего 104 записей REVIEW. Бытие 1–3 — 80 стихов последовательного пилота; Матфея 5–7 — 111 стихов тематического блока. Это предварительная сегментация: некоторые записи объединяют стихи, некоторые выделяют разные мотивы одного стиха.

Никаких новых CORE или EXCLUDE за владельца не утверждено. Канон не выбран; проверен только Синодальный перевод, без сверки оригинальных языков и второго перевода. PDF/DOCX этой версии не создавались.

## Воспроизводимость

[Скрипт v0.1](build_bible_pilot.py) сохраняет первоначальную сборку; [скрипт расширения](extend_bible_v02.py) использует сохранённые редакционные данные в `research/v0.2/` и файлы v0.1. Для сборки реестра нужен Python с openpyxl. Скрипт не исследует источники автоматически и не заменяет повторной научной проверки.
