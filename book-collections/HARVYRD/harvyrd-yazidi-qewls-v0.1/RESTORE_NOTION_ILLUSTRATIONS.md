# Восстановление полноразмерных иллюстраций из ZIP-частей Notion

Оригиналы PNG лежат в `assets/` без уменьшения разрешения. Каталог `notion-illustration-chunks/` содержит дополнительные ZIP_STORED-архивы для прикрепления к Notion, где лимит отдельных файлов не позволяет прикрепить исходные PNG целиком. Каждый ZIP меньше 4 MiB и хранит непрерывный диапазон исходных байтов без сжатия и потерь.

## Восстановление

1. Скачайте все части `*.zip` и файл `MANIFEST.json` в `notion-illustration-chunks/`. Имена частей заканчиваются на `.part01.zip`, `.part02.zip` и т. д.; части каждого рисунка нужно склеивать по этому числовому порядку.
2. Из корня папки книги выполните:

```sh
python3 scripts/restore_illustration_chunks.py --output-dir restored-illustrations
```

Скрипт проверит SHA-256 архива и байтовой части, ZIP CRC, метод ZIP_STORED, размер, непрерывность смещений и контрольную сумму восстановленного PNG. Он запишет файлы в `restored-illustrations/`, не меняя оригиналы.

Если вместе с архивами загружены и исходники из GitHub, сравните восстановление с оригиналами:

```sh
python3 scripts/restore_illustration_chunks.py --output-dir restored-illustrations --verify-originals
```

Для проверки всех опубликованных файлов папки книги, включая каждый ZIP, MANIFEST, полный исходник, PDF, DOCX и оригинальные PNG, из корня выполните:

```sh
sha256sum -c SHA256SUMS
```

`notion-illustration-chunks/MANIFEST.json` содержит SHA-256 каждого ZIP-файла и каждого необработанного сегмента, а также размер и SHA-256 каждого полностью восстановленного оригинала. Контрольные суммы исходных PNG и ZIP-частей также перечислены в `SHA256SUMS`.
