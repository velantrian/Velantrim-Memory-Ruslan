# Иллюстрации к «Чжоу и»

Комплект содержит три оригинальные иллюстрации, созданные специально для этой книги, и 64 схемы полученного порядка гексаграмм. У схем сплошная черта обозначает целую линию, разделённая — прерывистую; нижняя линия является первой. Схемы не задают меняющихся линий и не являются процедурой гадания.

`SHA256SUMS.json` перечисляет SHA-256 каждого изображения внутри архива. Все файлы — PNG.
