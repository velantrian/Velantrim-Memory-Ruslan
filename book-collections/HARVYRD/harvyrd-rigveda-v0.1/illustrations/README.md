# Иллюстрации к книге «Ригведа: семь голосов у истока»

Три оригинальные абстрактные иллюстрации созданы для читательского издания HARVYRÐ. В них нет воспроизведения исторических рукописей, ритуальных предметов или изображений божеств.

- `01-cover-art.png` — обложка: рассвет над тёмной водой.
- `02-dawn.png` — рассветный пейзаж к главе об Ушас.
- `03-cosmos-and-voice.png` — волны и линии звучания к главе о Вāк.

Иллюстрации включены в комплект книги; внутри самой книги они выполняют художественную, а не документальную или ритуально-реконструктивную функцию.
