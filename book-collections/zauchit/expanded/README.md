## Новый вопрос

Недостаточно измерять текущий успех. Нужно проверить, сохраняется ли способность учиться, переносить правила, исправлять ошибочные цели и помогать человеку без роста зависимости. Результаты публикаций, их интерпретации и гипотезы о Заучите различены. Новая часть не является аудитом кода, утверждённым Canon или свидетельством уже реализованных способностей.
