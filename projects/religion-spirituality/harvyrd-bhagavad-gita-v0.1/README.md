# HARVYRD «Бхагавадгита» — точная редакция v0.1

Это точный одобренный владельцем набор артефактов проекта **Бхагавадгита**, опубликованный в private-репозитории GitHub.

## Состав и охват

- **18 авторских литературных глав**; маршрут охватывает **18 исходных единиц**.
- Охват: литературный маршрут по восемнадцати главам свободного английского переложения Арнольда; точечная сверка XIII и XVIII по Телангу; не полный перевод и не постиховая разметка.
- Основа перевода/переложения: Edwin Arnold, The Song Celestial; главы XIII и XVIII — дополнительная опора K.T.Telang.
- В редакции: **4 новые иллюстрации** и **25 записи отбора**.
